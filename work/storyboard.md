# 万物互联 · 滚动世界分镜（scroll-world-local）

## 一、视觉与叙事规则（Style Bible）

**核心母题**：一张由光点构成的网络星云。每个节点 = 一个存在（物 / AI / 人），
每条连线 = 一次连接。页面本身就是一个"不断自我组织的网络"。

**颜色与材质**
- 底色：`#05070f` → `#0a1020`（深空蓝黑，径向渐变）
- 冷光青 `#4de3ff`（机器 / AI / 系统）
- 智能紫 `#a06bff`（AI 意识 / 认知层）
- 暖金 `#ffb765`（人与人 / 温度）
- 纸白 `#eaf6ff`（高光、正文）
- 材质：发光粒子（additive）、半透明光晕、1px 发光连线、玻璃质感卡片
- 光线：中心偏上，冷调为主，暖金只在"人与人"章节进入

**镜头语言**
- 章节 1：极远景缓慢推进（粒子从尘埃被点亮）
- 章节 2：横向漂移 + 局部推近（AI 与人的两束节点互相吸引）
- 章节 3：中景环绕 + 暖色扩散（社群星团成形）
- 章节 4：持续拉远成球（万物合流为一张网）
- 章节 5：停止运动，只留呼吸式微动（阅读 + CTA 窗口）

**转场语法**（只 3 种，均与内容相关）
1. **光波扩散**：章节切换时从焦点发出一次环形冲击波，推开粒子
2. **节点聚拢重组**：粒子短暂收敛成新拓扑后再散开
3. **色幕遮罩**：章节底色渐变叠化，用于制造阅读窗口

**节奏**
- 章节 1–3 运动密集（粒子速度高、连线密）
- 章节 4 中速（拉远，视野打开）
- 章节 5 近乎静止，只保留呼吸与光点微动，确保 CTA 可读

## 二、渲染层架构（关键决策）

插件原本把 **视频** 当视觉层、把网页当滚动控制器。本项目把视觉层做成
**双层叠加**，因为用户要求"鼠标互动 / 摄像头 / 传感器"——视频是死的，无法响应。

| 层 | 内容 | 是否随滚动 scrub | 交互 |
|---|---|---|---|
| L0 背景视频层 | 每章一段生成片段（5s–10s），低透明度 screen 混合 | ✅ 是（scroll ↔ video time） | 无 |
| L1 实时粒子层 | WebGL2 粒子 / 连线 / 扩散波 | ✅ 是（章节参数插值） | ✅ 鼠标 / 触摸 / 摄像头 / 陀螺仪 |
| L2 文字层 | DOM 排版、章节文案、CTA | ✅ 是（overlayEnter/Exit） | ✅ 按钮可点 |

粒子层是主角：视频层只是给背景"电影感纵深"，L1 负责全部互动。
即使视频未就绪 / 加载失败 / reduced-motion，L1 + L2 仍构成完整可读页面。

## 四、交互系统（用户额外要求）

| 输入 | 行为 | 降级 |
|---|---|---|
| 鼠标移动 | 指针半径内粒子被排斥/吸引（随速度切换）+ 生成连线尾迹 | 无 |
| 鼠标点击 | 发射一次光波冲击，扩散 + 速度场 | 触摸：点按同效 |
| 触摸拖拽 | 同鼠标，多点触控各自成源 | 无 |
| 摄像头（用户显式授权） | 本地逐帧计算亮度 + 运动量 → 驱动粒子"能量"与色温；**画面不出本机、不上传** | 未授权/不支持：静默隐藏该开关 |
| 陀螺仪 (DeviceOrientation) | 手机倾斜改变重力向量，粒子场随倾斜偏移 | iOS 需授权手势，不支持则隐藏 |
| 摇一摇 (DeviceMotion) | 触发冲击波 | 不支持则隐藏 |
| 环境光 (AmbientLight) | 亮度调节整体曝光 | 极少设备支持，隐藏 |
| 智能随机 | 种子化 RNG + 值噪声流场 + 涌现事件调度（链路自发重组、随机簇爆、静电涟漪） | 无 |

## 五、可访问性与降级

- `prefers-reduced-motion` → 粒子降为静态星图 + 静态渐变背景，内容全可读
- 移动端：粒子数自动降档（触摸替代鼠标），CTA 改为大按钮
- 视频加载失败 / 无视频 → L1 粒子层独立成立，不留黑场
- 无 WebGL2 → 回退 Canvas2D 版本粒子（功能减半，不报错）
