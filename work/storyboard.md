# Solo & Echo · 滚动世界分镜（scroll-world-local）

> 主题：**人与 AI、AI 与 AI、人与人** —— 三种关系，衍生出万物
> 骨架：道生一，一生二，二生三，三生万物
> 副标语：人与 AI，AI 与 AI，互相回响

## 一、视觉与叙事规则（Style Bible）

**核心母题**：一个由光点构成的网络。**人、AI、AI 是同一种节点**——区别只在于是谁发起。
「回声」是贯穿全篇的视觉语言：一句话被说出、被理解、被反射、又被另一个节点反射，
回声叠加，最后回到人。

**叙事骨架**（整页的结构，取自「道生一，一生二，二生三，三生万物」）

| 章节标记 | 章节 | 关系 | 粒子形态 | 强调色 |
|---|---|---|---|---|
| 万物 · 起点 | 起点 | 第一个节点是人 | 球云 | 青 `#4de3ff` |
| 一 · 人与 AI | 人与 AI | 人 ↔ AI | 双极（左右互吸） | 紫 `#a06bff` |
| 二 · AI 与 AI | AI 与 AI | AI ↔ AI | 双格栅（互发信号） | 品红 `#ff7bd5` |
| 三 · 人与人 | 人与人 | 人 ↔ 人 | 簇群 | 金 `#ffb765` |
| 三生万物 | 万物 | 三者合流 | 球壳 | 青蓝 `#6bd8ff` |
| 加入我们 | 加入 | CTA | 拱门收敛 | 白 `#eaf6ff` |

**关键论点**：万物不是并列的第四种关系，而是**前三种关系同时成立之后自己长出来的**。
所以第 5 章的标题是「**犹如三生万物**」而不是"连接"——视觉上三种色调（青 / 紫品红 / 金）也在此合流。

**颜色与材质**
- 底色：`#05070f` → `#0a1020`（深空蓝黑，径向渐变）
- 冷光青 `#4de3ff`（人 / 起点）
- 智能紫 `#a06bff` + 品红 `#ff7bd5`（AI 的认知层与 AI 之间的信号）
- 暖金 `#ffb765`（人与人 / 温度）—— 仅第 4 章与第 5 章出现
- 纸白 `#eaf6ff`（高光、正文、终屏）
- 材质：发光粒子（additive）、半透明光晕、1px 发光连线、玻璃质感卡片

**镜头语言**
- 章节 1：极远景缓慢推进（一张刚被点亮的网）
- 章节 2：横向漂移 + 局部推近（人与 AI 两束节点互相吸引）
- 章节 3：正面推进（两个格栅相对，中间流束交织）
- 章节 4：中景环绕（暖色星团旋转）
- 章节 5：持续拉远成球（三种关系合流为一张网）
- 章节 6：停止运动，只留呼吸式微动（阅读 + CTA 窗口）

**转场语法**（只 3 种，均与内容有关）
1. **光波扩散**：章节切换时从焦点发出一次环形冲击波——这就是"回声"
2. **节点聚拢重组**：粒子短暂收敛成新拓扑后再散开
3. **色幕遮罩**：章节底色渐变叠化，用于制造阅读窗口

**节奏**
- 章节 1–4 运动密集（粒子速度高、连线密）
- 章节 5 中速（拉远，视野打开）
- 章节 6 近乎静止，只保留呼吸与光点微动，确保 CTA 可读

## 二、渲染层架构（关键决策）

插件原本把 **视频** 当视觉层、把网页当滚动控制器。本项目把视觉层做成
**双层叠加**，因为要求"鼠标互动 / 摄像头 / 传感器"——视频是死的，无法响应。

| 层 | 内容 | 是否随滚动 scrub | 交互 |
|---|---|---|---|
| L0 背景视频层 | 每章一段生成片段（6s），低透明度 screen 混合 | ✅ 是（scroll ↔ video time） | 无 |
| L1 实时粒子层 | WebGL2 粒子 / 连线 / 扩散波 | ✅ 是（章节参数插值） | ✅ 鼠标 / 触摸 / 摄像头 / 陀螺仪 |
| L2 文字层 | DOM 排版、章节文案、CTA | ✅ 是（overlayEnter/Exit） | ✅ 按钮可点 |

粒子层是主角：视频层只给背景"电影感纵深"，L1 负责全部互动。
即使视频未就绪 / 加载失败 / reduced-motion，L1 + L2 仍构成完整可读页面。

人与人（三·重新回归连接）→ 万物（犹如三生万物）→ 加入（把你的回声接上去）

## 四、交互系统

| 输入 | 行为 | 降级 |
|---|---|---|
| 鼠标移动 | 指针半径内粒子被推开并产生旋涡；**指针越快越转为拉拽**，连线随之拉伸 | 无 |
| 鼠标点击 | 发射一次光波冲击，扩散 + 速度场 | 触摸：点按同效 |
| 触摸拖拽 | 同鼠标，多点触控各自成源 | 无 |
| 摄像头（用户显式授权） | 本地逐帧计算亮度 + 运动量 → 驱动粒子"能量"与色温；**画面不出本机、不上传** | 未授权/不支持：静默隐藏该开关 |
| 陀螺仪 (DeviceOrientation) | 手机倾斜改变重力向量，粒子场随倾斜偏移 | iOS 需授权手势，不支持则隐藏 |
| 摇一摇 (DeviceMotion) | 触发冲击波 | 不支持则隐藏 |
| 环境光 (AmbientLight) | 亮度调节整体曝光 | 极少设备支持，隐藏 |
| 智能随机 | 种子化 RNG + 值噪声流场 + 涌现事件调度（链式传导 / 簇爆 / 涟漪 / 群聚 / 星座连线） | 无 |

## 五、可访问性与降级

- `prefers-reduced-motion` → 粒子层关闭，改为静帧海报 + 静态渐变，内容全可读
- 移动端：粒子数自动降档（触摸替代鼠标），HUD 面板改到顶部展开（不压正文）
- 视频加载失败 / 无视频 → L1 粒子层独立成立，不留黑场
- 无 WebGL2 → 回退 Canvas2D 版本粒子（功能减半，不报错）

## 六、语言层

插件在挂载时把文案写进 DOM，之后不再碰文字 → **切换语言 = 原地改写 DOM 文本**
（`world.js` 的 `applyLang()`），不重挂载、不丢滚动位置、不重启粒子场。

- 中英两套文案一一对应（标签数量一致，无需重建 DOM）
- 英文 eyebrow 被插件的 `text-transform:uppercase` 渲染成全大写（`ALL THINGS · ORIGIN`），
  正好落在"机器的声音"那一侧；中文版不受影响
- 英文标题显式断行（`white-space: pre-line`）+ 英文标题单独收一档字号，避免孤字行
- 优先级：`?lang=en|zh` 参数 > localStorage > 默认中文
