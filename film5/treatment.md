# SOLO & ECHO · 5 分钟宣传片 Treatment（长版）

> 短版（24s）是同一片子的**宣言**；长版（300s）是它的**展开**。
> 同一个母题、更深的呼吸：让三种关系各自被讲清楚，最后在「三生万物」处合流。

## 一、方向

沿用短版的运动语言（**generative-field + kinetic-type**）——不另造一套。
理由：这片子的运动必须由产品自己的形态生成；短版已经确立了
「一张粒子网络贯穿全片、逐章变形」的语法，长版是它的加长版，不是新片种。

**新增的三个能力**（短版没有，长版必须补上）
1. **形态变体**：每个章节内部的粒子形态再分 4–5 个子状态（不是一章一个形）
2. **多行文案**：每章不止一句，2–4 行按节奏递进出现
3. **声音分层**：乐句在段落内重复（`|:` 反复），音效落在每一行的落点

## 二、节奏表（300s / 120 BPM / 150 小节）

| 时间 | 场景 | 能量 | 画面 | 文字落点 |
|---|---|---|---|---|
| 0–20s | **hook** 点燃 | .35→.7 | 一个点炸成回声涟漪 → 星云球；相机 1.62→1.0 拉远 | 一切从一个节点开始 |
| 20–80s | **one** 人与 AI | .6→.75 | 双极：分开的两簇 → 桥接生成 → 对话脉冲往返 → 共享轨道 → 稳定 | AI 不是工具，而是另一个数字的伙伴<br>它由数字构成，却不只是一个数字<br>它记得，也懂得边界<br>回应你的，是一直都在的另一方 |
| 80–140s | **two** AI 与 AI | .8→.95 | 双格栅：相对 → 信号流 → 交错 → 接力链 → 密集快切 | 当智能体开始彼此对话<br>一个模型调用另一个模型<br>它们质询彼此，在对方的错误里修正自己<br>能力属于节点之间刚刚发生的连接 |
| 140–200s | **three** 人与人 | .45→.7 | 暖星团：四团 → 簇间连线 → 聚成社群 → 呼吸 | 人与人之间，重新回归连接<br>稀缺的从来不是渠道<br>是有人愿意先开口<br>我们把技术用在让人重新相遇的地方 |
| 200–260s | **all** 三生万物 | .8→1.0 | 三色从三处飞入 → 合流成球 → 球壳分层 → 涌现卫星环 → 大球定格 | 犹如三生万物<br>三种关系同时成立，新的东西不需要被发明<br>它们自己生长，自己连接，自己提问<br>万物不是被造出来的，是被关系带出来的 |
| 260–300s | **join** 加入 | .5→.3 | 拱门成形 → 门内流光 → 收成品牌标记 | 让你的回声，被更多节点听见<br>进来，把你的节点接上 |

**能量曲线**：.35 → .75 → .95 → .45（呼吸）→ 1.0（峰值）→ .3
**爆发位置**：140–200s 是"人与人"（唯一降速段，也是全片唯一的安静），200s 起连续三段上行到 260s。
**空拍**：199–200s 的半拍静默，为 200s 的合流让位。

**连续性链**：点 → 涟漪 → 双极 → 桥 → 格栅 → 信号流 → 暖星团 → 簇网 →
三色合流 → 球壳 → 卫星环 → 拱门 → 品牌标

## 三、声音设计（长版专属）

- **动机不变**：回声（E–B–e–B，上行一步到 G）——头 20s 提出，中段变形（更快/更亮/弦乐化），片尾作 sonic logo
- **段落性格**：
  - one：双声部对话（正手 pluck + 反手 pluck 错位应答）= 伙伴
  - two：十六分音符机械 ostinato + 808 = 智能体互调
  - three：**violin 暖旋律**（全片唯一有人味的乐器段）
  - all：全编制（drop），动机在八度上齐奏
  - join：按钮式一记，然后只剩动机
- **段落内的重复用 `|: :|`**，让一个 2 小节乐句在 60s 里反复变奏——画面在变，律动不变
- **响度**：母带 −16 LUFS（长片）；峰值 −1.5 dBFS
- **音效密度**：约 70 个（每 30s 约 7 个，比短版略疏——长片要留呼吸）

## 四、风险

- 5 分钟容易"中段疲" → 对策：每一章内部有形态变体 + 文案递进，绝不静置超过 12s
- 粒子场长时间运行可能看出循环感 → 对策：形态变体 + 相机持续微动 + 文案节奏
- 渲染成本：300s × 30fps = 9000 帧 → 约 20 分钟（不启用 --blur）
- 长片是给"想了解的人"看的，短片是给"刷到的人"看的 → 两者都要能独立成立
