# SOLO & ECHO · 5 分钟宣传片 Treatment（长版 · 19 分镜）

> 短版（24s）是同一片子的**宣言**；长版（300s）是它的**展开**。
> 同一个母题、更深的呼吸：三种关系各自拆成 5 个**具体场景**，
> 每个场景一个独立画面 + 一句具体的话，然后「三生万物」把它们合流。

## 一、方向

沿用短版的运动语言（**generative-field + kinetic-type**）——不另造一套。
这片子的运动必须由产品自己的形态生成：短版已经确立了
「一张粒子网络贯穿全片、逐章变形」的语法，长版是它的加长版。

**长版新增的三个能力**
1. **19 个分镜**：每种关系拆成 5 个具体场景（不是抽象形容词）
2. **每个分镜一种形态**：19 种看得懂的画面（追问 / 补全 / 反驳 / 记得 / 边界…）
3. **硬切转场**：每次换镜 = 一次白闪 + 硬切 + 一记音效，绝不溶解

**画面语言（长版确立）**
- **左文右景**：文案固定在左侧竖排区，粒子形态整体右移 330px，左侧叠一层压暗渐变
  ——任何形态都不会压住字，文案永远可读
- **形态坐标一律以画面中心为原点**（0,0 = 中心），渲染层再乘镜头、加半屏偏移
- 分镜切换：白闪 0.07s 峰值 / 0.34s 衰减 + 硬切 + whoosh / hit / glitch 三选一循环

## 三、声音设计（长版专属）

- **动机**：回声 E–B–e–B（上行一步到 G）—— 0s 提出，20s 变形，270s 收成 sonic logo
- **时间网格**：`M:2/4` `L:1/8` `Q:1/4=120` → 1 小节 = 1.00s；1 cell = 8 个音符 = 1 小节
- **段落性格**
  - hook：只有拨弦 + 低音（**鼓不进**）—— 第一个关系成立时脉搏才进来
  - one：动机 + 错位应答 = 伙伴
  - two：机械 ostinato + 808 + hi-hat = 智能体互调
  - three：**violin 暖旋律**（全片唯一有人味的乐器段）
  - all：全编制（drop），动机升八度 + impact/subdrop
  - join：动机收束成品牌音
- **响度**：母带 −14 LUFS，峰值 −1.5 dBFS
- **音效**：47 个（18 个分镜切换 whoosh/hit/glitch + 20 个文案落点 pop + 5 个 kicker tick
  + 尾卡 stamp/ding + 涌现 impact/subdrop）
- **磁带停转**：在 DH 声部（该段本来静默）的 rest 尾部写 `!stop(! … !stop)!`，
  覆盖 225–230s

## 四、踩过的坑（改代码前先读）

1. **`E/B/e/B/` 这种斜杠写法，结尾的 `/` 被解析成"长度 0.5"** → 每个音只有 0.25 拍；
   而 `E,,2` 是 1 拍。两种写法**差一倍**，混用会让整条声部长度错位
2. **解析器不做声部补齐**：各声部每段长度必须完全一致，否则短的那个整体前移
   （上一版 DH/VLN 只有部分段落 → 镲片和弦乐全跑到片头）
3. **每个声部必须压成一行**：重复逻辑用声部级 `lastRepeat` 比对**行内** token 下标，
   分行写会让每行第二个 `|: :|` 不再重复（第一块 10s、其余每块 5s）
4. **形态坐标只能有一套**：旧版 17 个形态用绝对坐标、渲染层又加半屏偏移 → 粒子全跑出画面
5. **文案退场要算在下一行进场前**（起点章两行曾叠字）；尾卡 289s 淡入 → join 文案 286s 前走
6. **`|: … :|` 后接 `|: … :|` 是安全的**；但 `:| :|` 会让解析器死循环 OOM
