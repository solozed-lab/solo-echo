# SOLO & ECHO · 5 分钟宣传片 Treatment（v2 · 网页同源版）

> v1 的教训：上一版用 canvas 2D 画圆点贴图 + 离散角色色，**和网页完全不是一套东西**。
> 这一版把网页的渲染引擎整个搬进片子，片子里的每一帧就是网页里的那种画面。

## 一、渲染层：与 `site/assets/js/field.js` 同源

直接搬用网页的三件事，**逐字继承**（视觉完全同源）：

| | 网页 | 片子 |
|---|---|---|
| 渲染 | WebGL2 + 两支 GLSL 着色器 | 同一份 GLSL |
| 点 | 径向衰减软光点（`pow(1-d, 2.4)`） | 同一份 |
| 线 | 扁平着色 + 空间网格（cell = link 距离） | 同一份算法 |
| 调色板 | 三色**连续**插值（`palette(h, c1,c2,c3)`），粒子各自带 hue | 同一份 |
| 粒子 | 1872，World 58% / AI 18% / Human 17% / Core 7%，hue 按角色分布 | 同一套分布 |
| 章节参数 | 每章一组 link / linkAlpha / size / energy / flow | 同一套 |

**唯一的区别**：网页的粒子位置是 rAF + 实时积分（有速度、有惯性、会飘散），
影片必须**每一帧可复现**，所以位置改成**时间的纯函数**：

```
目标形态 → 流场噪声位移（把硬边化成雾）→ 每粒子轨道 → 相机变换
```

代价：没有惯性，粒子会结成死结（见第五节），所以底形态的中心必须留空。

## 二、两层形态架构

一屏画面同时表达两件事：**底形态 = 这一章的世界**（网页的 6 个体积形态），
**特征层 = 这一分镜在发生什么**（19 个标志物）。

| 底形态（网页原样） | 特征层（分镜标志物） |
|---|---|
| `sphere` 星云球 | 一点炸成回声涟漪 |
| `bipolar` 双极 | 追问弧 / 反驳的排斥缝 / 记忆节点环 / 边界线 / 来回信号弧 / 共享记忆的直连 / 陌生人那一瞬的连线 / 温度的暖流 |
| `lattice` 双格栅 | 两列代码条带 / 三个节点的接力链 / 横穿的信号流 / 一线分裂成多条 |
| `cluster` 簇群 | 凌晨三点的四个人 |
| `shell` 壳 | 涌现的合流射线 |
| `sphere` | 新能力长出来的簇 / 螺旋自聚 |
| `gate` 拱门 | 加入 |

**特征层必须用独立的抽签量 `psel`**，不能复用 `pv`
（`pv` 是底形态的半径分布，用它抽签等于把底形态掏成空壳）。

## 三、呼出框（信号卡）

**基因来自站点「加入」弹框**：深色玻璃面板 + 1px 内描边 + 顶部三色细线。

| 元素 | 规格 |
|---|---|
| 位置 | 左侧 88px 起，宽 620px，垂直居中 |
| 面板 | `rgba(8,12,22,.62) → rgba(5,8,16,.70)`，1px `rgba(234,246,255,.10)`，圆角 4px（编辑感，不是 UI 卡片） |
| 顶部细线 | 章节三色，`scaleX(.28) → 1`，从中间向两侧画出 |
| 框外柔光 | radial-gradient（不用 backdrop-filter —— 叠在实时 WebGL 上每帧重糊会掉帧） |
| 眉题 | 等宽小字，章节色（`一 · 人与 AI`） |
| 编号 | 右上角 `02 / 19` |
| 主句 | 50px / 900 字重 + 章节色柔光投影（继承站点 `.sw-copy__title`） |
| 证据句 | 25px，`rgba(234,246,255,.72)`，站点正文的灰度 |

**入场**（0.62s，错峰四层）：面板升 26px + scale .975→1 → 120ms 后三色线画出
→ 180ms 后主句 → 300ms 后证据句。**不做逐字动画**（逐字是网页感太重的东西）。
**退场**：整体上移 16px + 淡出 + blur(3px)，0.45s。

## 四、转场与过渡（不用全屏白闪）

分镜切换 = **三件事同时发生**，都是网页的语言：

1. **形态接力**：新旧两个形态的粒子目标在 0.95s 内插值（粒子始终在动，只是目的地在换）
2. **扩散波环**：从画面中心推开一圈 56 段的圆环，3.2s 内扩散并淡出
   （网页 `field.js` 的 shock ring —— 它的招牌动作）
3. **相机呼吸**：转场瞬间 zoom 退 2.5%，再缓缓回到分镜自己的机位

章节切换（5 次）额外加：`whoosh` + `subdrop` 两记音，画面上调色板整体交叉溶解 1.6s。

## 五、音效编排：只落在意义的落点

长片要留呼吸，**不是每次切换都响**。

| 事件 | 音效 | 次数 |
|---|---|---|
| 呼出框出现 | `pop`（0.26） | 19 |
| 章节切换 | `whoosh` + `subdrop` | 5 + 5 |
| 意义落点（反驳 / 七个人都回了 / 凌晨三点） | `thud` | 3 |
| 万物章（涌现 / 不是被造出来的）+ 尾卡 | `chime` | 3 |
| 尾卡 | `impact` | 1 |
| 乐谱的 `!hit!`（涌现瞬间） | impact + subdrop | 1 |

共 38 个。分镜切换本身**不出声**——静音本身就是转场。

## 六、配乐

自写 ABC（`work/analysis/make_long_score.py` 生成）：
`M:2/4` `L:1/8` `Q:1/4=120` → 1 cell = 8 音符 = 1 小节 = 1.00s；1 块 = `|: 乐句 :|` = 10s。

| 章节 | 时长 | 块数 | 乐器 |
|---|---|---|---|
| 起点 | 30s | 3 | 只有拨弦 + 低音（**鼓不进**）——第一个关系成立时脉搏才进来 |
| 一 · 人与 AI | 80s | 8 | 动机 + 错位应答；低频心跳；小鼓轻点 |
| 二 · AI 与 AI | 80s | 8 | 机械 ostinato + 808 + hi-hat |
| 三 · 人与人 | 80s | 8 | **violin 暖旋律**（全片唯一有人味的乐器段） |
| 犹如三生万物 | 40s | 4 | 全编制，动机升八度 + `!hit!` |
| 加入 | 30s | 3 | 动机收束成品牌音 |

6 个 `!mark:` 精确落在 0 / 30 / 110 / 190 / 270 / 310s，每段弯率 **0.4%**（= 零弯率）。
能量轮廓 −22.0 → −16.2 → −14.9 →（磁带停转）−16.2 → **−14.6 峰值** → −16.6 dB RMS。
母带 −14 LUFS，峰值 −1.5 dBFS。

## 七、这一版踩到的坑

1. **形态坐标只能有一套**：形态返回**以画面中心为原点**的坐标，渲染层再乘镜头、加半屏偏移。
   形态里写绝对坐标（CX/CY）= 偏移两次 = 粒子全跑出画面。
2. **特征层的抽签量必须独立**（`psel`），否则底形态被掏空，只剩一圈空壳。
3. **粒子不能全部堆到同一个点**：`firstword` 的连线在进度到 1 时会让 22% 的粒子挤在终点，
   加色混合直接烧出一个白方块；线要"长出来"（每粒子按自己的位置取线上的点）。
4. **底形态的中心要留空**（半径分布的最小值 0.08 → 0.20）：
   网页靠弹簧把粒子抖开，影片是纯函数没有抖，`sqrt` 分布会在中心结成死结。
5. **热点不能按角度取样**：按 `pu`（极角）取样时同一角度的粒子一起亮 → 在极点上叠成白块。
   改成**空间扫描带**（一道从左往右扫过全场的亮区）。
6. **composition variables 不能丢**：重写 `index.html` 时漏了 `data-composition-variables`，
   `OM.vars()` 返回空对象 → 品牌 / CTA / 域名全是空的。
7. **GSAP `fromTo` 要带 `immediateRender:false`**，否则所有元素在第 0 帧就同时可见。
